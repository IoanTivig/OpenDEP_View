# The graph and images

## Above the graph

- **Re[CM(f)]** / **DEP Force**: what the curves show. The force uses each curve's particle radius and ∇E²; scatters (Re[CM] values) are drawn only with Re[CM(f)].
- **Graph size**: the padlock fixes the size of the figure; then type its width and height in pixels (the size of a saved image follows it). Open, the graph follows the size of the window and the two fields show its current size.

## Under the graph

| Button | Action |
|---|---|
| home | back to the full view |
| zoom | drag a rectangle to zoom in |
| settings (gear) | graph settings (below) |
| image | save the graph as an image (below) |
| bars / area (right) | errors of the scatters as error bars or as a shaded area |

## Graph settings

| Part | Settings |
|---|---|
| Font | family of all text |
| Axis titles | size, weight, style, distance to the axis |
| Tick labels | size, weight, style, distance; major and minor ticks: shown, direction, length, width |
| Grid | horizontal and vertical lines: shown, line type, width, transparency |
| Legend | shown, font size, weight, style, position |
| Frame | line width; which sides are drawn |

The settings are saved with the project.

## Saving an image

| Field | Meaning |
|---|---|
| Name, folder | where the image is written (default: the Desktop) |
| Format | PNG, TIFF or JPG |
| DPI | 72 to 1200; journals usually ask for 300 (photos) or 600 to 1200 (line art) |
| Colour | colour or grayscale |
| Size | the graph's size, or a fixed width and height in pixels |

The image is drawn at its final size, never enlarged or squeezed afterwards:

- **The graph's size**: the same layout as on screen, at the chosen resolution. A graph of 640 × 480 px on screen (6.4 × 4.8 in) saved at 600 DPI is 3840 × 2880 px.
- **A fixed size**: the graph is laid out for exactly that width and height. For a figure of a given width in a paper: pixels = width in inches × DPI (8.5 cm = 3.35 in at 600 DPI = 2008 px).

Text keeps its size in points, as in the paper. On a small figure (one column, 8.5 cm) choose smaller fonts in the graph settings, about 8 to 10 pt; the on-screen graph is much wider than a printed column.
